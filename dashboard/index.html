    Model classes

    Pick which exposed model fills each Claude Code role, or leave on auto (first exposed model for opus/sonnet/fable, second for haiku/subagent).

    Points ~/.claude/settings.json at this proxy with the bearer-gateway recipe: ANTHROPIC_AUTH_TOKEN carries the gateway key, ANTHROPIC_API_KEY is blanked and gateway model discovery is enabled so every exposed model appears in /model. Restart Claude Code after applying.

    Claude Desktop

    Adds an “ecoGPT” gateway profile to Claude Desktop and activates it, pinned to the Bearer auth scheme with exposed models seeded into the picker. Quit Claude Desktop completely first, then relaunch after applying — the app encrypts the key on next start.
