    One-click setup

    Claude Code

    Model classes

    Pick which exposed model fills each Claude Code role, or leave on auto (first exposed model for opus/sonnet/fable, second for haiku/subagent).

    Points ~/.claude/settings.json at this proxy with the bearer-gateway recipe: ANTHROPIC_AUTH_TOKEN carries the gateway key, ANTHROPIC_API_KEY is blanked and gateway model discovery is enabled so every exposed model appears in /model. Restart Claude Code after applying; restore reverts byte-for-byte.

    Claude Desktop

    Adds an "ecoGPT" gateway profile to Claude Desktop and activates it, pinned to the Bearer auth scheme with the exposed models seeded into the picker. Quit Claude Desktop completely first, then relaunch after applying — the app encrypts the key on next start. Restore swaps back the byte-for-byte backup.

    Region & calibration

    Per-model green profile

    EcoLogits Calculator expert-mode inputs for each exposed model: model parameters (Active/Total B), published averages (TPS, TTFT) and the datacenter scenario (PUE, on-site WUE, location, grid mix). Values prefilled from the pinned EcoLogits catalogue where available; blank datacenter fields fall back to the region scenario above (grid water comes from the electricity dataset, shown per model with its source).

    If a model's parameters are not known, either Estimate them (stratified public IKP probes against the gateway — paced for free-tier rate limits, auto-retry, resumable: if it stops you can press Continue later without rerunning from scratch) or enter values manually. An estimate is a knowledge-equivalent scenario, not a verified weight count — it is applied only when you press Apply estimate. Water, ADPe and primary energy always display together with their provenance caption.
